# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Do not** open a public GitHub issue for security-sensitive reports.

Instead, use GitHub Security Advisories on this repository, or contact the maintainers through a private channel.

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Scope

This project includes cross-chain bridge smart contracts and a relayer service. Reports related to fund loss, signature forgery, replay attacks, or privilege escalation are especially welcome.

## Disclaimer

This software is provided without warranty. Use at your own risk. Audits may not cover all deployment configurations.
